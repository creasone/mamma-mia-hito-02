# Pizzería Mamma Mía - Hito 2

Aplicación desarrollada con React, Vite y JavaScript para el segundo hito del proyecto Pizzería Mamma Mía de Desafío Latam.

## Funcionalidades

- Navbar con opciones condicionadas por un token simulado.
- Home y total de compra siempre visibles.
- Header con título y descripción.
- Catálogo de tres pizzas construido con componentes y props.
- Diseño responsive para escritorio, tablet y dispositivos móviles.
- Footer con la información solicitada en la rúbrica.
- Navegación local entre Home, Login y Register.
- Formularios controlados con `useState` y eventos de React.
- Validación de campos obligatorios y contraseña mínima de 6 caracteres.
- Confirmación de contraseña en el registro.
- Mensajes de error y éxito accesibles, sin backend ni JWT.

## Instalación

```bash
pnpm install
```

También puedes utilizar `npm install` si tienes npm disponible.

## Ejecución

```bash
pnpm dev
```

## Compilación

```bash
pnpm build
```

El proyecto corresponde únicamente al alcance del Hito 2. No implementa backend, JWT ni autenticación real.
